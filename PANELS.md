# Manuscript panel guide

Panel labels refer to the manuscript figures. Script filenames can reflect earlier panel numbering; use the mapping below rather than inferring labels from filenames. Run the module workflow to build prerequisite tables and caches. Output is written under that module’s `output/` directory.

**Code** denotes a numerical plot generated here. **Mixed** denotes a generated plot combined with external artwork or images. **External** denotes a panel whose reconstruction is outside these five analysis workflows. Final multi-panel page composition is external.
